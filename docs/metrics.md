# Metric definitions

- **First touch:** all conversion credit goes to the first recorded touch in a synthetic path.
- **Last touch:** all conversion credit goes to the final recorded touch.
- **Linear:** credit is split equally across recorded touches.
- **Attributed orders/revenue:** conversion/order value allocated using the selected rule; fractional orders are expected under linear attribution.
- **ROAS:** attributed revenue divided by media spend for paid channels in the selected window.
- **CAC:** paid media spend divided by paid-attributed conversions.
- **Conversion rate:** attributed conversions divided by tracked sessions; directionally useful in this synthetic demo, not an experimental causal estimate.
- **Forecast:** 14-day planning baseline from recent weekday averages with a small trend adjustment. It is intentionally simple and explainable.
- **Quality score:** a demo roll-up that deducts two points for each validation category requiring review. It is a visible prioritization aid, not a universal data-quality standard; the detailed quarantines and check results remain the source of truth.
